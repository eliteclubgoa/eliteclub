# The Elite Club

Boooking website for **The Elite Club Casino**, a premium offshore casino experience on the Mandovi River in Panaji, Goa.

The site presents the casino experience, games, package options, gallery, accommodation partners, contact information, and legal information. Calls to action connect visitors to the booking platform or WhatsApp enquiries.

## Features

- Dark, luxury-focused responsive design with Playfair Display and Manrope typography.
- TanStack Router file-based routes with client-side navigation and scroll restoration.
- Server-rendered application powered by TanStack Start and Nitro.
- Casino overview, gaming catalogue, package comparison, image gallery, and contact page.
- WhatsApp enquiry links and external booking, hotel, agent portal, notice, and social links.
- Legal pages for important information, terms, OTPC terms, and refund/cancellation policy.
- Shared header, footer, responsive mobile menu, animated reveal components, CTA buttons, and reusable UI primitives.
- Root-level 404 and error states, plus server-side error handling and CSRF protection for server functions.

## Requirements

- Node.js ES2022-compatible runtime. Node.js 20 or newer is recommended.
- npm or Bun.

No environment variables are required by the current application. External service URLs and contact details are centralized in `src/lib/site.ts`.

## Getting started

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd majestic-pride-hub
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will print the local URL in the terminal. The configured Vite integration may select an available host or port when necessary.

### Bun

The repository includes `bun.lock`, so Bun can be used instead of npm:

```bash
bun install
bun run dev
```

├── src/
│   ├── assets/             # Casino, gallery, hotel, and video assets
│   ├── components/

│   ├── hooks/               # Shared React hooks
│   ├── lib/
│   │   ├── data.ts         # Games, casinos, hotels, gallery, and image data

│   ├── routes/             # TanStack Router route components
│   ├── router.tsx          # Router and QueryClient configuration
│   ├── server.ts           # SSR server entry and error normalization
│   ├── start.ts            # TanStack Start middleware configuration

`src/routeTree.gen.ts` is generated by TanStack Router tooling. Do not edit it manually; update the corresponding file in `src/routes/` instead.

## Updating site content

Common content changes should be made in the following locations:

- Brand name, phone, email, address, booking links, social links, and navigation: `src/lib/site.ts`.
- Games, casinos, hotels, gallery entries, and image references: `src/lib/data.ts`.
- Page-specific content and SEO metadata: the relevant file in `src/routes/`.
- Shared page chrome: `src/components/site/Header.tsx` and `src/components/site/Footer.tsx`.
- Colors, typography, spacing, and global utility styles: `src/styles.css`.

When adding an image, place it under `src/assets/` and import it from the component or data module that uses it. Vite will include imported assets in the build with the correct hashed URL.

## Build and deployment

The project uses the Lovable TanStack Vite configuration in `vite.config.ts`. That integration configures the TanStack Start, React, Tailwind, TypeScript path alias, and Nitro build plugins. The custom server entry is `src/server.ts`.

To verify a production build locally:

```bash
npm run build
npm run preview
```

Deploy the generated application using a hosting target supported by the Nitro adapter selected by the Vite configuration. Confirm the target's TanStack Start/Nitro instructions before deploying, especially for SSR, external redirects, and the custom `src/server.ts` entry.
